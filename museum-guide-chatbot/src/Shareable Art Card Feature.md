# Shareable Art Card — Feature Brief

## What it does

After the user explores an artwork with the Muse chatbot, they can click a **"Share"** button that generates a beautifully designed card containing:

- The artwork image
- Title, artist, and year
- One key insight line generated by OpenAI
- The Muse branding

The card is rendered on an HTML `<canvas>` element and exported as a downloadable PNG.

---

## How it works

1. User clicks "Generate Art Card" in the chat UI
2. Frontend calls `GET /api/card/:sessionId`
3. Backend fetches the session's artwork from MongoDB + requests a one-line insight from OpenAI
4. Returns JSON: `{ imageUrl, title, artist, year, insight }`
5. Frontend draws everything onto a `<canvas>` and triggers a PNG download
