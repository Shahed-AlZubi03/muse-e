## Feature Overview

After a user has explored an artwork through the Muse chatbot, they are offered a short interactive quiz generated by OpenAI. The quiz tests the knowledge they just gained from the conversation — covering the artwork's history, technique, artist biography, and symbolism.

The quiz makes the experience go from passive reading to active learning, significantly increasing engagement and session depth. Scores are tracked per session and, if user auth is present, across a user's full history.

**Goal:** Turn Muse from a tour guide into a learning platform.

**Core value:** Every quiz is unique — generated dynamically by OpenAI based on the actual conversation that just happened, not a static question bank.

## User Flow

```
User explores artwork via chat
        │
        ▼
Guide sends final message:
"Would you like to test what you've learned? I can quiz you on this painting."
        │
        ├── User says "yes" / clicks "Start Quiz"
        │           │
        │           ▼
        │     OpenAI generates 5 questions
        │     based on the conversation history
        │           │
        │           ▼
        │     Questions displayed one at a time
        │     (multiple choice, 4 options each)
        │           │
        │           ▼
        │     User answers each question
        │           │
        │           ▼
        │     Instant feedback per answer
        │     (correct/wrong + short explanation)
        │           │
        │           ▼
        │     Final score card shown
        │     (X/5 + performance message)
        │           │
        │           ▼
        │     Score saved to MongoDB session
        │
        └── User says "no" → conversation continues normally
```

## Quiz Structure

Each quiz has exactly **5 questions**, each with **4 multiple choice options** (A, B, C, D), one correct answer, and a short explanation for why the correct answer is right.

### Question categories (one per quiz, no repeats)

| # | Category | Example |
|---|---|---|
| 1 | Factual | "In what year was The Starry Night painted?" |
| 2 | Artist biography | "What personal struggle was Van Gogh experiencing at the time?" |
| 3 | Technique | "Which brushstroke technique defines the swirling sky?" |
| 4 | Symbolism | "What does the cypress tree in the foreground traditionally represent?" |
| 5 | Art movement / context | "Which movement does this painting belong to?" |

### Difficulty levels

- **Novice** — straightforward factual questions, all answers in the conversation
- **Scholar** — requires inference and deeper knowledge beyond the chat
- **Expert** — subtle symbolism, comparisons to other works, historical nuance

Default is **Novice**. Users can request a harder level: "Quiz me like an expert."

## Technical Architecture

```
Client sends: POST /api/quiz/generate
        │
        ▼
Load session from MongoDB
(get full message history + artworkId)
        │
        ▼
Fetch artwork data from MongoDB
(curatorNotes, funFacts, movement, artist)
        │
        ▼
Build OpenAI prompt:
- System: quiz generator persona
- Context: artwork data + conversation history
- Instruction: generate 5 JSON questions
        │
        ▼
OpenAI returns structured JSON quiz
        │
        ▼
Validate + save quiz to MongoDB (Quiz collection)
        │
        ▼
Return quiz to client (questions only, no answers yet)

--- User answers one by one ---

Client sends: POST /api/quiz/:quizId/answer
{ questionIndex: 2, selectedOption: "B" }
        │
        ▼
Compare against stored correct answer
Return: { correct: true/false, explanation: "..." }

--- After all 5 answers ---

Client sends: POST /api/quiz/:quizId/complete
        │
        ▼
Calculate final score
Save score to Session document
Return: { score: 4, total: 5, badge: "Art Enthusiast" }
```

## Database Schema Changes

### New collection: `quizzes`

```js
// models/Quiz.js
const questionSchema = new Schema({
  index: Number,
  category: {
    type: String,
    enum: ['factual', 'biography', 'technique', 'symbolism', 'movement']
  },
  question: String,
  options: {
    A: String,
    B: String,
    C: String,
    D: String
  },
  correctOption: {
    type: String,
    enum: ['A', 'B', 'C', 'D']
  },
  explanation: String,           // Why the correct answer is right
  userAnswer: {
    type: String,
    enum: ['A', 'B', 'C', 'D', null],
    default: null
  },
  isCorrect: {
    type: Boolean,
    default: null
  }
})

const quizSchema = new Schema({
  sessionId: {
    type: String,
    required: true,
    index: true
  },
  artworkId: {
    type: Schema.Types.ObjectId,
    ref: 'Artwork',
    required: true
  },
  difficulty: {
    type: String,
    enum: ['novice', 'scholar', 'expert'],
    default: 'novice'
  },
  questions: [questionSchema],
  score: {
    type: Number,
    default: null                // null = not completed yet
  },
  completedAt: {
    type: Date,
    default: null
  }
}, { timestamps: true })
```

### Update to `Session` schema

Add a `quizzes` reference field:

```js
quizzes: [{ type: Schema.Types.ObjectId, ref: 'Quiz' }],
bestScore: { type: Number, default: null }
```

## API Endpoints

### `POST /api/quiz/generate`

Generates a new quiz for a session.

**Headers:** `x-api-key: your-key`

**Body:**
```json
{
  "sessionId": "abc123",
  "difficulty": "novice"
}
```

**Response:**
```json
{
  "quizId": "64f3a...",
  "difficulty": "novice",
  "questions": [
    {
      "index": 0,
      "category": "factual",
      "question": "In what year was The Starry Night painted?",
      "options": {
        "A": "1874",
        "B": "1889",
        "C": "1901",
        "D": "1882"
      }
    }
  ]
}
```

Note: `correctOption` and `explanation` are NOT returned here — only after the user answers.

---

### `POST /api/quiz/:quizId/answer`

Submits an answer for a single question.

**Body:**
```json
{
  "questionIndex": 0,
  "selectedOption": "B"
}
```

**Response:**
```json
{
  "correct": true,
  "correctOption": "B",
  "explanation": "Van Gogh painted The Starry Night in June 1889 during his stay at the Saint-Paul-de-Mausole asylum.",
  "questionsRemaining": 4
}
```

---

### `POST /api/quiz/:quizId/complete`

Finalizes the quiz and saves the score.

**Response:**
```json
{
  "score": 4,
  "total": 5,
  "percentage": 80,
  "badge": "Art Enthusiast",
  "breakdown": [
    { "category": "factual", "correct": true },
    { "category": "biography", "correct": false },
    { "category": "technique", "correct": true },
    { "category": "symbolism", "correct": true },
    { "category": "movement", "correct": true }
  ]
}
```

---

### `GET /api/quiz/session/:sessionId`

Returns all quizzes taken in a session (for review).
